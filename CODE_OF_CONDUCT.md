# Code of conduct

Treat participants with respect. Welcome questions, give constructive feedback
about the work, respect privacy, and accept good-faith disagreement.

Harassment, threats, discriminatory language, personal attacks, impersonation,
spam, and publication of private information without consent are unacceptable.
These expectations apply to issues, pull requests, reviews, and other official
project spaces.

Report conduct concerns privately through GitHub's reporting tools or contact
the maintainer through the [project owner's profile](https://github.com/JAAvila-Of).
Include links and enough context for review. Maintainers may remove content,
limit participation, or block accounts. Maintainers handle reports discreetly
and share information only as needed to respond.
