# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/JAAvila-Of/elnor/security/advisories/new).
Use a public issue for ordinary defects only. Keep credentials, private
source, personal data, and security reproducers out of public discussions.

Include the affected version or revision, platform, impact, required
conditions, and a minimal synthetic reproduction. If a credential has been
exposed, revoke it at the issuer immediately.

The maintainers investigate reports in the advisory and coordinate disclosure
with a fix where possible. Security fixes target the latest experimental
release. Elnor is under active development and has no long-term support or
guaranteed response time.
